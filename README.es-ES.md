

# Investigación en Redes Neuronales Informadas por la Física (PINNs)

## Descripción general

Este repositorio está dedicado a la implementación y exploración de Redes Neuronales Informadas por la Física (PINNs) utilizando los marcos de trabajo DeepXDE y TensorFlow. Las PINNs son un enfoque novedoso para resolver ecuaciones diferenciales que se ven informadas por las leyes de la física, lo que las hace particularmente útiles para aplicaciones de computación científica. Este repositorio contiene ejemplos y experimentos sobre diversas ecuaciones, demostrando el poder y la versatilidad de las PINNs en el modelado de sistemas físicos complejos.

## Características

- **Resolutores de ecuaciones**: Implementaciones para resolver ecuaciones de Allen-Cahn en 1D y 2D, ecuaciones de calor y problemas inversos utilizando PINNs.
- **Visualización**: Scripts para generar gráficos y videos con el fin de visualizar el proceso de entrenamiento y los resultados.
- **Gestión de datos**: Utilidades para manejar datos de entrada y salida, incluidos conjuntos de datos de temperatura y divisiones de entrenamiento/prueba.
- **Registros**: Registro detallado de las sesiones de entrenamiento para el monitoreo del rendimiento y la depuración.
